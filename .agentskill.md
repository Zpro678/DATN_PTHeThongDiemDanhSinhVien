# 🎓 AgentSkill — EduTrack: Hệ Thống Điểm Danh Sinh Viên
**Branch:** `develop_v2` | **Stack:** Laravel 11 + Livewire 4 + TailwindCSS + AlpineJS

> File này là nguồn chân lý cho AI agent. Tuân thủ TUYỆT ĐỐI, không được tự ý thay đổi bố cục, thiết kế, hoặc cấu trúc nếu không có chỉ thị rõ ràng từ người dùng.

---

## 1. 🏗️ Tổng Quan Dự Án

**Tên hệ thống:** EduTrack — Hệ thống điểm danh sinh viên  
**Mục tiêu:** Quản lý điểm danh, lớp học, đơn xin nghỉ phép, thống kê chuyên cần cho giảng viên và sinh viên.

### Hai không gian người dùng chính:
| Vai trò | Chức năng chính |
|---------|----------------|
| **Chủ lớp (Lecturer)** | Quản lý lớp, tạo buổi điểm danh, duyệt đơn xin nghỉ, xem thống kê |
| **Học viên (Student)** | Tham gia lớp, điểm danh QR, xem lịch sử, gửi đơn xin nghỉ |

| `primary` | `#004ac6` | Màu chủ đạo, CTA, active state |
| `on-primary` | `#ffffff` | Text trên nền primary |

| `on-primary-container` | `#eeefff` | Text trên primary-container |
| `secondary` | `#5a5f62` | Text phụ, icon |
| `tertiary` | `#006242` | Màu thứ 3 (xanh lá) |
| `error` | `#ba1a1a` | Lỗi, cảnh báo, logout |
| `error-container` | `#ffdad6` | Nền cảnh báo nhẹ |
| `background` | `#f8f9ff` | Nền trang |
| `surface` | `#f8f9ff` | Nền component |
| `on-surface` | `#0b1c30` | Text chính |
| `on-surface-variant` | `#434655` | Text phụ |
| `surface-container-lowest` | `#ffffff` | Sidebar, card |
| `surface-container` | `#e5eeff` | Nền chip, badge |
| `surface-container-high` | `#dce9ff` | Nền hover |
| `outline-variant` | `#c3c6d7` | Border, divider |
| `alert-container` | `#fff0ef` | Alert/warning box |

```
│  <main> CONTENT AREA (flex-1)                       │
│  ├── <header> Sticky Header (h-16)                  │
│  │   ├── [Search area - empty]                      │
│  │   ├── [Học phần mới] + [Tham gia lớp] buttons    │
│  │   ├── Notification bell (dropdown)               │
│  │   ├── Settings button                            │
│  │   └── User avatar + dropdown                     │
│  └── #main-scroll-area (overflow-auto)              │
│      └── {{ $slot }}                                │
│                                                     │
│  <nav> MOBILE BOTTOM NAV (md:hidden)               │
│  └── FAB button (floating action button)            │
└─────────────────────────────────────────────────────┘
```

### Các quy tắc layout KHÔNG ĐƯỢC VI PHẠM:
1. ✅ Sidebar **chỉ hiển thị** trên `md:` trở lên (`hidden md:flex`)
2. ✅ Mobile bottom nav **chỉ hiển thị** trên mobile (`md:hidden`)
3. ✅ `#main-scroll-area` là vùng scroll duy nhất, không thêm overflow trên `<body>` hay `<html>`
4. ✅ Header phải `sticky top-0 z-40` với `backdrop-blur-md`
5. ✅ FAB button luôn `fixed bottom-6 left-1/2 -translate-x-1/2 md:hidden`
6. ✅ Mọi page content đặt trong `{{ $slot }}` của layout `user.blade.php`

## 7. 🚏 Route Structure

Routes định nghĩa trong `routes/web.php`:

### Auth Routes (`routes/auth.php`)
- Login, Register, Password Reset, Email Verification

### Dashboard
- `GET /dashboard` → `dashboard` (named: `dashboard`)

### Lecturer Routes (prefix: `/lecturer`, group: `lecturer`)
- `managed-classes` — Danh sách lớp quản lý
- `create-class` — Tạo học phần mới
- `lecturer.class.show` — Chi tiết lớp
- `lecturer.attendance.*` — Quản lý điểm danh
- `lecturer.students.*` — Quản lý sinh viên
- `lecturer.leave-requests.*` — Duyệt đơn xin nghỉ

### Student Routes (prefix: `/student`, group: `student`)
- `joined-classes` — Danh sách lớp tham gia
- `student.classes.show` — Chi tiết lớp
- `student.attendance.history` — Lịch sử điểm danh
- `student.attendance.stats` — Thống kê chuyên cần
- `student.leave-requests.*` — Đơn xin nghỉ
- `student.warnings` — Cảnh báo

### Profile Routes
- `profile.*` — Hồ sơ cá nhân

## 8. ⚙️ Livewire Component Pattern

### Cách đặt tên file:
- **PHP class:** `app/Livewire/{Role}/{PascalCase}.php`
- **Blade view:** `resources/views/livewire/{role}/{kebab-case}.blade.php`

### Ví dụ chuẩn:
```php
// app/Livewire/Student/AttendanceHistory.php
namespace App\Livewire\Student;

use Livewire\Component;

class AttendanceHistory extends Component
{
    // Properties
    public $classId;
    
    // Lifecycle hooks
    public function mount($classId = null) { ... }
    
    // Actions
    public function someAction() { ... }
    
    // Render
    public function render()
    {
        return view('livewire.student.attendance-history')
            ->layout('layouts.user', ['title' => 'Tên trang']);
    }
}
```

### Layout binding:
```php
// Luôn dùng layout user.blade.php với title
->layout('layouts.user', ['title' => 'Tên trang'])
```

## 10. 🎯 Quy Tắc Coding — BẮT BUỘC

### ✅ ĐƯỢC PHÉP:
- Thêm tính năng mới trong phạm vi component/service hiện có
- Tạo Livewire component mới theo pattern đã định nghĩa
- Thêm migration mới (không sửa migration cũ)
- Refactor logic business trong `Services/`
- Thêm route mới theo đúng prefix/group hiện có
- Sửa nội dung text/label tiếng Việt

### ❌ NGHIÊM CẤM:
- Thay đổi cấu trúc layout `user.blade.php` (sidebar, header, footer)
- Thay đổi color tokens trong `tailwind.config.js`
- Thay đổi font family (Outfit)
- Thêm CSS framework khác (Bootstrap, etc.)
- Thêm thư viện icon khác ngoài Lucide (qua `x-user.icon`)
- Sửa migration đã chạy
- Thêm package PHP/JS mà không thông báo cho người dùng
- Thay đổi cấu trúc thư mục đã định nghĩa
- Dùng màu hardcode thay vì design token
- Tạo file CSS/JS mới ngoài `resources/css/app.css` và `resources/js/app.js`

### 🔄 CẦN HỎI NGƯỜI DÙNG TRƯỚC KHI:
- Thêm package mới vào `composer.json` hoặc `package.json`
- Thêm bảng database mới (migration)
- Thay đổi permission/role logic
- Thay đổi cấu trúc route
- Sửa `tailwind.config.js`

```php
public function save()
{
    $this->validate();
```
